## What "built-in AI" actually means

_Beat: Gemini Nano ships inside Chrome; the browser exposes it as web APIs. No backend, no API key, no per-request cost, nothing leaves the device._

## The API family

_Beat: one table mapping each API to what it does and where it lives in the course._

## Why on-device

_Beat: privacy, zero cost, low latency, offline — and the honest cost: a few GB of model, desktop-only, variable hardware._

## The one pattern every API shares

_Beat: `availability()` → `create()` → use → `destroy()`. Learn it once here; every later page reuses it._

Every API in this course starts the same way — you ask whether it's available
before you use it:

<CodeTabs>
```js
// Every built-in AI API answers availability() the same way:
// "unavailable" | "downloadable" | "downloading" | "available"
const status = await LanguageModel.availability();

if (status === 'available') {
  const session = await LanguageModel.create();
  console.log(await session.prompt('Say hi in one word.'));
  session.destroy();
}
```
```ts
type Availability =
  | 'unavailable'
  | 'downloadable'
  | 'downloading'
  | 'available';

const status: Availability = await LanguageModel.availability();

if (status === 'available') {
  const session: LanguageModel = await LanguageModel.create();
  console.log(await session.prompt('Say hi in one word.'));
  session.destroy();
}
```
</CodeTabs>

:::
